2. Menu utilisateur enrichi

En mobile (≤ 600 px), les deux boutons topbar migrent dans le menu utilisateur : « Référence des classes » et « Mode clair / sombre » sont inserees au-dessus de l'entree existante « Changer de thème » (separateur de couple de couleurs, conserve tel quel). Le libellé « Mode clair / sombre » (validé V1) evite toute confusion avec le selecteur. Ces deux entrees sont toujours presentes dans le menu, quel que soit l'ecran (le menu est le point d'acces unique sur mobile).
