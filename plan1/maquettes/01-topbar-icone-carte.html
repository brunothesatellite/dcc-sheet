1. Icone « carte » de la topbar

Nouveau bouton #btn-carte place immediatement a gauche de l'icone de theme (#btn-theme), dans le bloc de droite de la topbar, apres le .topbar-spacer. Clic = ouverture du module de dessin en plein ecran (maquette 02). Visible uniquement pour un utilisateur connecte (D5) : les invites conservent la topbar actuelle.

Rendu desktop
Dungeon Crawl Classics
1Position : l'icone carte est a gauche de l'icone theme, jamais entre le logo et le spacer (elle doit rester dans le groupe d'actions de droite, alignee avatar / theme).
2Style : clone exact de .theme-toggle (36 px, cercle, fond blanc 10 % sur le bandeau sombre) — meme cercle, meme survol. En tactile la cible reste a 44 px via la zone de clic du bouton (padding invisible).
3Icone : symbole #i-map de draw-on-map (plan deplie, trait 1,8 px) — il est reutilise tel quel dans le module (pastille « cartes » de la barre haute).
4Connecte uniquement : sans session, les API de sauvegarde refusent (401) — l'icone n'apparait donc pas pour les invites (comme le menu utilisateur). Variante possible : icone visible + message « Connectez-vous pour dessiner ».
Rendu mobile (≤ 600 px)
Dungeon Crawl Classics
Clerc — Frère Anselme
Exemple de contenu masque par le module plein ecran.
5Mobile : meme ordre (carte puis theme). Le logo se compresse deja en ≤ 600 px, l'ajout ne provoque pas de defilement horizontal (les deux pastilles font 36 px + 8 px d'ecart).
6Zone cliquable : le bouton fait 36 px comme .theme-toggle, mais sa zone tactile est portee a 44 px (pseudo-element etendu) — regle d'accessibilite de l'application.
7Ouverture : un seul clic ouvre le module en plein ecran (maquette 02) ; rien d'autre ne bouge derriere (aucun rechargement, l'etat des fiches est conserve).
