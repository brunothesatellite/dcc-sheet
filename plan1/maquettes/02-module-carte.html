2. Module de dessin « carte » — plein ecran

Page de dessin occupe 100 % de l'ecran (#map-module, position:fixed; inset:0; z-index:3000) par-dessus l'application, sans rechargement. Fonctions identiques a draw-on-map : crayon, gomme, texte, deplacer, annuler, palette de 6 couleurs, zoom (+/curseur/100 %/ajuster/pincement), multi-cartes, feuilles « Plus / Export / Import / Cartes / Options ». Ajouts propres a l'integration : croix de fermeture (3), fond webp servi par api/map-image.php?uid=… (5), toast de sauvegarde pendant le dessin (voir maquette 04).

Rendu mobile — palette de couleurs ouverte
1Chrome haut flottant : chip etat (outil actif), chip cartes (compteur), chip zoom, puis la croix. Il se masque des qu'un doigt touche la carte et reapparait au relachement (comportement draw-on-map).
2Zoom mémorisé : 125 % ici — repris de la base a la reouverture (maps.ui.zoom), avec la position de defilement (R13).
3Croix de fermeture (nouveau, R3) : 38 px visibles / 44 px cliquables, meme langage que .spell-viewer-close. Ferme sans confirmation (tout est deja en base) + touche Echap.
4Dock : 7 actions, 46 px, en bas = zone du pouce ; la pastille de couleur ouvre le tiroir de 6 couleurs (ci-dessous, ouvert).
5Fond webp : <img> jamais modifie, servi par api/map-image.php?uid=…. Le dessin reste sur un canvas transparent au-dessus (aucun pixel d'image n'est jamais recopié).
Rendu desktop — outil texte actif
Touchez la carte pour placer
6Desktop : meme composants, largeur libre ; les feuilles s'ouvrent centrees (et non en feuille basse), le curseur est crosshair en crayon / move en deplacement. Le pointeur souris passe par la meme machine a etats que le doigt.
7Outil texte : l'etagere contextuelle pousse le dock vers le bas ; tap/clic sur la carte = placement du texte (taille exprimee en px ecran, convertie en unites de scene au moment du placement).
Variante — aucune image de fond (grille de repli)
8Grille de repli (.md-scene.is-empty) : conservee quand aucune image n'est definie et quand une image referencee par UID est introuvable a l'import (R11) — le dessin reste lui toujours affiche.
