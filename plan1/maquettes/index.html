Evolution « Carte » — maquettes

Documents de travail pour la branche evol-draw-map — maquettes HTML statiques, aucune logique applicative. Elles se servent du style.css reel de l'application pour etre au plus pres du rendu final. Source de la spec : TODO.md § EVOLUTIONS — plan detaille : plan1/PLAN-CARTE.md — application de reference : D:\VS Code\draw-on-map.

Les 4 maquettes
1. Icone « carte » de la topbar
Bouton place a gauche de l'icone de theme · style clone de .theme-toggle · rendus desktop et mobile · visible uniquement pour un utilisateur connecte
2. Module de dessin plein ecran
Chrome haut + croix de fermeture · scene avec fond webp, dessin vectoriel, grille de repli · dock 7 actions, tiroir de couleurs, etagere texte · mobile et desktop
3. Feuilles et dialogues
Feuille « Plus » · tiroir des calques (UID visibles) · options de la carte (image : nom + UID + suppression) · export/import JSON et ZIP · menu utilisateur « tout »
4. Sauvegarde, toasts et flux
Toast de sauvegarde pendant le dessin · toasts d'erreur (image introuvable, image trop lourde) · flux image / suppression / import ZIP / reouverture · arbitrages (limite 10 cartes, concurrence, conversion webp)
Ce que les maquettes arbitrent
D1 une « carte » = un calque persiste (maps) · A1 images en data/maps/[UID].webp, servies par PHP · A2 outil/couleur globaux, zoom/position par calque · A3 ZIP construit cote serveur · D5 icone reservee aux utilisateurs connectes · D7 toasts de la couche globale · R11 image introuvable = toast d'erreur + grille par defaut.
