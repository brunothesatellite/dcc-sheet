5. Entrée menu « Référence »

Nouvelle entrée « Référence » (data-action="full-ref"), placée au-dessus de « Classes » — la complète d'abord (ordre à valider, R2). Visible sur tous les écrans dès que contentref est détecté ; invisible sinon (même condition html.has-ref-reader que le bouton topbar). Icône livre + lignes en ::before (même technique que « Classes ») — tracé retenu selon R1.

Rendu desktop — menu ouvert sous l'avatar
Dungeon Crawl Classics
Bienvenue Bruno
1Ordre (R2) : bienvenue · Référence (nouveau) · Classes · Mode Sombre · Changer de thème · … Le clic ouvre la même visionneuse que le bouton topbar (DCCRefReader.openReference()) et referme le menu, comme les autres entrées.
2Icône : ::before 16 px en CSS — livre + lignes (A) ou bibliothèque (B) selon R1 ; l'icône ☾/☀ de la bascule et la pastille du sélecteur restent inchangées.
Rendu mobile (≤ 600 px) — menu ouvert
Dungeon Crawl Classics
Bienvenue Bruno
3Mobile : « Référence » est l'accès unique à la complète (bouton topbar masqué) — même pattern que « Classes » hier. Tient sur une ligne comme les autres entrées (libellé court, pas de retour ligne).
4Contenu absent ou ancien : sans contentref (absent ou ancien déploiement avec seulement content/), l'entrée disparaît du menu (html:not(.has-ref-reader)) sans erreur ni toast — le menu retrouve exactement sa forme actuelle, sans trou ni séparateur orphelin. Les sorts, eux, continuent de fonctionner.
5Zéro persistance : la visionneuse est volatile (comme « Classes »), rien en base ni en localStorage.
